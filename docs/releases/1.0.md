# SirisLearn 1.0

The first release.

- **Courses on anything.** Type a topic, pick a level (beginner, intermediate, advanced) and a size (short, standard, deep dive), and optionally say what to focus on or skip. Claude plans the course as sections of lessons.
- **Lessons, then quizzes.** Each lesson is a 5 to 10 minute read with a diagram and key points, followed by a 10-question quiz: multiple choice and written answers, at least three of them about a picture. Answers are marked straight away with an explanation; written answers are marked by Claude against the lesson's key points.
- **Progress.** XP, levels, a daily XP goal, daily streaks and 24 awards (bronze to platinum), with progress shown on the locked ones.
- **History.** A six-month activity heatmap, totals (XP, lessons passed, accuracy, time in quizzes) and a day-by-day timeline of everything you've read, passed and unlocked.
- **SirisOS.** A hub API (`/api/hub/v1/status`, `/summary`, `/search`) for the SirisOS tile, widget, search and inbox.
- **Starter course** ("How to learn anything faster") so the app works before a model is set up.
- Liquid Glass UI matching the Siris apps, installable as a PWA.
