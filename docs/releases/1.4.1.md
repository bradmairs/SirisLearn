# SirisLearn 1.4.1

- **Versions are now Section.Feature.Fix**, the same as SirisOS and SirisAI: a fix adds 0.0.1, a feature 0.1.0, a new section 1.0.0. The last release, 1.4, is 1.4.0 in the new numbering. `scripts/bump-version.sh fix|feature|section` writes it everywhere and starts these notes; merging a version change to main tags and releases it. See docs/releases.md.
